# Portfolio project description

## TestForge AI — Intelligent Test Automation Studio

TestForge AI transforms plain-English testing requirements into structured requirement interpretations, coverage-oriented test plans, reusable Python automation projects, static validation results, and downloadable project packages.

### Features

- Natural-language QA scenario intake.
- Positive, negative, resilience, and concurrency test design.
- Python API framework generation with pytest and Requests.
- Generated project manifests, fixtures, clients, configuration, and documentation.
- Path safety, secret-pattern, syntax, and manifest validation.
- Request IDs, security headers, bounded requests, and baseline rate controls.
- Render and Docker deployment configuration.
- Explicit separation between generated, validated, executed, and approved states.

### Technology stack

Python, FastAPI, Pydantic, Uvicorn, pytest, Requests-based generated projects, HTML/CSS/JavaScript, Docker, GitHub Actions, and Render-compatible deployment configuration.
